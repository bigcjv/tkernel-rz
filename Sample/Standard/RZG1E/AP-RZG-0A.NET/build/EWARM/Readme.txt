■ はじめに
───────────────────────────────────────

  RZ/G1E用のサンプルプログラムの使用方法を説明します。本サンプルプログラムは
  OSの起動とネットワークの実装例になります。ネットワークのアプリケーションは
  下記が動作します。
  
    DHCPクライアント
    DNSクライアント
    PINGクライアント
    HTTPサーバー
    FTPサーバー (簡易ファイルシステム(RAMディスク))
  
  なお、本サンプルプログラムのスタートアップルーチンはMMUの初期化とスタック
  ポインタの設定のみを行います。よって、本サンプルの起動前にブートローダーで
  クロックやメモリなどの初期化を行ってください。

■ ソースコードの変更
───────────────────────────────────────
  必要に応じて次のコードを変更してください。
  
   ・DHCPによるIPアドレスの取得を無効にする場合はnet.cにある下記の定義値を
     0に変更してください。
    
      #define DHCP_ENB    0       /* DHCP無効 */
    
   ・IPアドレスとMACアドレスの設定はnet_cfg.cのgNET_ADRとgNET_DEVを
     変更してください。
     
   ・DNSクライアントの通信相手となるDNSサーバのIPアドレス
  
    ファイル 
      sample_net_app_cfg.h
    変更箇所
      SPL_DNS_SERVERの定義を変更してください。
      #define SPL_DNS_SERVER   ((192U << 24) | (168U << 16) | (1U << 8) | (1U))

■ デバッグ実行
───────────────────────────────────────
  ビルドの手順、評価ボードへダウンロードの手順は、
  チュートリアルガイド(TutorialGuide_CortexA7MP_RZG1E.pdf)のUARTサンプルの
  手順と同じです。
  ワークスペースを開く際のファイルはsample_net.ewwを指定してください。
  
  実行するとターミナルエミュレータに次の例のように文字列が表示されます。
  
              Sample Program for eForce Operating System V1.0
                      Serial Port (SCIF 2)
      
      DHCP: Success
      
      uC3 Shell 1.0
      
      Shell>
    
    ターミナルでは次のコマンドが使用できます。
    
      ip    : IPアドレスの表示
      ipcfg : IPアドレスの設定
      dns   : ドメイン名のIPアドレスを表示（DNSによる名前解決）
      ping  : ping（送信）
    
    使用例は次のようになります。
    
      Shell>ip
      devID=1:
       IP Address  : 192.168.1.103
       Subnet Mask : 255.255.255.0
       Gateway     : 192.168.1.1
      
      Shell>ipcfg
       Enter new values..
       IP Address  : 192.168.1.102
       Subnet Mask : 255.255.255.0
       Gateway     : 192.168.1.1
      
      Shell>dns www.eforce.co.jp
      xxx.xxx.xxx.xxx
      
      Shell>ping 192.168.1.1
       ping request successful
    
    評価ボードではHTTPサーバーが動作しています。ウェブブラウザで評価ボードの
    IPアドレスのページを開くことができます。また、HTTPサーバーではCGIが使用
    できます。ウェブブラウザでcgi_valに値を入力して"Set"のボタンを押すと
    ターミナルに次の例のように文字列が表示されます。
    
        CGI: cgi_val set to 123
    
    さらに、評価ボードではFTPサーバーが動作しています。FTPクライアントで
    評価ボードのFTPサーバーに接続することができます。接続時のユーザー名と
    パスワードは入力せずにEnterキーを押してください。ファイルの転送例は次のように
    なります。FTPサーバーが受信できるファイルサイズの上限は4Kバイトです。
    
        C:\>ftp 192.168.1.103
        192.168.1.103 に接続しました。
        220 Connected to FTP Server
        ユーザー (192.168.1.103:(none)): <-無し
        331 User name okay, need password
        パスワード: <-無し
        230 User Logged in
        ftp> put test.txt
        200 Okay
        150 About to open data connection
        226 Transfer okay
        ftp: 512 バイトが送信されました 0.03秒 16.52KB/秒。
        ftp> bye

■ イーサネットドライバ設定
───────────────────────────────────────
  イーサネットドライバ(DDR_RZG1_ETH.c)の設定はファイルのDDR_RZG1_ETH_cfg.h
  にマクロを設定します。イーサネットの割り込み優先度を設定するマクロ(
  CFG_ETH_IPL)は必ず設定してください。その他のマクロは設定しないことが可能
  です。設定しない場合はデフォルトの設定値になります。
  各マクロの設定内容はファイルのDDR_RZG1_ETH_cfg.hのコメントをお読みくださ
  い。
  
  イーサネットドライバは下記のOSの資源を使用します。
  
             種類            個数
    ------------------------ ----
    割り込みサービスルーチン  1
    タスク                    3
    イベントフラグ            1
    メールボックス            2
  
  イーサネットドライバでは下記の3つのタスクが動作します。
  
                     関数名                 優先度設定マクロ
    ------- -------------------------- ------------------------
    タスク1  ddr_rzg1_eth_tsk_snd      CFG_ETH_TSK_SND_PRI
    タスク2  ddr_rzg1_eth_tsk_rcv      CFG_ETH_TSK_RCV_PRI
    タスク3  ddr_rzg1_eth_tsk_rcv_tcp  CFG_ETH_TSK_RCV_TCP_PRI
  
  タスク1は送信タスクです。TCP/IPプロトコルスタックから受け取ったパケットを
  物理層へ送信します。タスク2は受信タスクです。タスク2で物理層からパケットを
  受信し、タスク2はタスク3へ受信したパケットを渡します。タスク3は受信した
  パケットをTCP/IPプロトコルスタックで処理します。
  
  イーサネットドライバが内部で使用する送信/受信バッファは非キャッシュ領域に
  配置してください。
  DDR_RZG1_ETH_cfg.hの次のマクロで送信/受信バッファを配置するセクション名
  を指定します。
  
    #define CFG_ETH_BUF_AREA    "UNCACHE"
